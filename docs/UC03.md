# UC03 Cadastrar Turmas

Branch `feat/UC03-cadastrar-turmas`, baseada em `feat/UC01-cadastro`, com as interfaces de cadastro e login existentes. Integra a API de turmas já implementada, anteriormente identificada como UC02. Esta entrega segue a numeração do DOCX atualizado: UC01 cadastro, UC02 login, UC03 turmas.

Em **Turmas**, professor da disciplina e coordenador podem consultar suas ofertas, cadastrar, editar, inativar/reativar, gerar e copiar código de acesso e habilitar/desabilitar autoinscrição. Cursos e docentes são consultados na API; o servidor restringe as operações ao vínculo vigente. O código bruto de acesso aparece somente na geração e é armazenado como hash.

A interface preserva os campos em erros de validação/duplicidade e exige ETag para alterações. Recarregar turma é explícito quando há conflito. O padrão de código EST + sigla + número segue o levantamento consolidado, o protótipo e o back end. O DOCX chama o campo de alfanumérico sem definir outro padrão. Os códigos de resposta legados UC_02 da API foram preservados; os textos e a interface seguem o UC03 atual.

Ordem dos novos casos: UC03 → UC04 (matrículas) → UC06 (trabalho e vínculo de orientação) → UC05 (atas do trabalho). Não é necessário integrar os UCs 09–11 para usar essas quatro branches.

Na raiz: `yarn dev`, `yarn test`, `yarn build` e `yarn test:e2e`. O banco deve estar preparado conforme `INICIAR.md`. O teste de navegador usa API Flask real com banco em memória e contas sintéticas, sem acessar o `.env` do usuário.
